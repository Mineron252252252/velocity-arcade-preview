# Локальные трейлеры

Интерфейс подхватывает ролик выбранной игры по локальному пути, запускает его без звука и зацикливает. Если файл отсутствует или не открывается, остаётся фон из обложки.

Файлы в этой папке:

- `project-cars.mp4` — подключён.
- `city-car-driving.mp4` — добавить.
- `carx-drift-racing.mp4` — добавить.
- `dirt-rally-2.mp4` — добавить.

Рекомендуемый формат — MP4 с H.264, до 1080p.
