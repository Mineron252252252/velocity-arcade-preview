# Паспорт проекта Auto

## Назначение

Полноэкранный аркадный интерфейс выбора автомобильных игр для аттракциона на Windows. Главная задача — создать выразительное игровое меню с плавной каруселью, удобное для управления мышью и клавиатурой.

## Текущее состояние

- Реализован статический веб-прототип на HTML, CSS и JavaScript.
- Публичный предпросмотр: https://mineron252252252.github.io/velocity-arcade-preview/
- Публикация выполняется GitHub Actions в GitHub Pages при push в `main`.
- Запуск игр пока не подключён; клавиша Enter показывает временное уведомление.

## Игры

1. Project CARS
2. City Car Driving
3. CarX Drift Racing
4. DiRT Rally 2.0

## Принятые решения

- Основа экрана тёмная, стиль аркадный, с неоновыми акцентами.
- Карусель показывает выбранную игру по центру и по одному соседу с каждой стороны; скрытая четвёртая карточка появляется при переключении.
- Карточки имеют единый вертикальный формат. Рамка выбранной карточки должна совпадать с пропорциями обложки при изменении размера и масштаба окна.
- Выбранная карточка отображается в масштабе 1,35 от базового; верхняя панель и подпись над каруселью скрыты, расстояние до блока названия адаптировано под размер карточки. Под карточкой оставлено только название игры; кнопка запуска, стрелки, точки, подсказка и описание убраны. Боковые карточки раздвинуты от центра на 100% собственной ширины.
- Все четыре игры используют обложки единого вертикального формата: Project CARS — `assets/project-cars-card.jpg`, City Car Driving — `assets/city-car-driving-card.png`, CarX Drift Racing — `assets/carx-drift-card.png`, DiRT Rally 2.0 — `assets/dirt-rally-card.png`.
- Активные карточки с обложками обведены симметричным угловым неоновым контуром с ровными сторонами; цвета контура подобраны под каждую обложку.
- За каруселью предусмотрен сменяемый фон для трейлера выбранной игры: без звука, с затемнением и плавным переходом. Для Project CARS подключён локальный трейлер; для остальных игр используется мягко анимированная обложка, пока не добавлены их видеофайлы.
- Карточки переключаются мышью, перетаскиванием и стрелками клавиатуры; Enter показывает временное уведомление о запуске.
- Переключение сохраняет плавность центрального фокуса. Карточки, уходящие за пределы видимой пары, исчезают без плавного затухания.
- Проект должен работать без внешних сетевых ресурсов.

## Структура

- `index.html` — разметка интерфейса.
- `styles.css` — тема, адаптивная компоновка и переходы.
- `app.js` — данные игр, навигация и триггер запуска.
- `assets/` — обложки и изображения.
- `.github/workflows/deploy.yml` — публикация GitHub Pages.
